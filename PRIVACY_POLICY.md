# ControlHome – Privacy Policy

Last updated: 2026-06-26

ControlHome is an Android client application for Domoticz. It connects to the Domoticz server configured by the user.

## Data collection

ControlHome does not collect, sell or share personal data with the developer or with third parties.

The app does not operate a ControlHome cloud backend.

## Data processed by the app

The app may process the following data locally on the user's device:

- Domoticz server address and port
- SSL and connection settings
- Domoticz username, if configured
- Domoticz password, stored locally in protected storage
- device names and states received from the configured Domoticz server
- room, favourite, scene, group and user variable data received from Domoticz
- local app settings such as tile appearance, background, reorder settings and Quick Settings tile configuration
- cached Domoticz data used for faster startup and offline display

This data is used only to provide the app's smart home control functionality.

## Network communication

ControlHome communicates with the Domoticz server configured by the user.

Depending on the user's configuration, this server may be:
- on the local network
- reachable through a private VPN
- reachable through a remote address configured by the user

ControlHome does not send Domoticz data to a ControlHome-operated server.

## Credentials

If login is enabled, the Domoticz password is stored locally on the device using Android protected storage.

The password is not intentionally included in Android backup.

## Photos and background images

If the user chooses a custom background image or room image, the app stores access to the selected image on the device. The image is used only for local visual customization inside the app.

## Analytics and advertising

ControlHome does not currently use advertising SDKs.

ControlHome does not currently use analytics SDKs.

## Payments and donations

The Play-distributed app is intended to be free.

Any optional project support link, if provided outside the app, is separate from the app's functionality and does not unlock in-app features.

## Children's privacy

ControlHome is not specifically directed at children. It is intended for users operating a Domoticz smart home system.

## Changes

This privacy policy may be updated when the app changes. The latest version should be published together with the project documentation.

## Contact

For questions about this privacy policy, contact the developer through the contact information listed on Google Play or on the GitHub project page.
